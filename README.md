# 工具箱

无需安装依赖的静态网页工具。

## 功能

- `index.html`：批量解析“姓名 + 电话”，生成 Android 可导入的 VCF 通讯录文件。
- `whatsapp.html`：批量生成 WhatsApp `wa.me` 链接；支持从 Excel/表格粘贴姓名和号码，并复制 A 列结果。

## 使用

直接用浏览器打开 `index.html`，再从左侧切换工具即可。

所有联系人数据只在当前浏览器中处理，不会上传到服务器。

## 发布到 GitHub Pages

1. 将本文件夹上传到一个独立的 GitHub 仓库。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择从分支部署，并选择 `main` 分支的 `/ (root)` 文件夹。
4. 保存后等待 GitHub 提供网站地址。
